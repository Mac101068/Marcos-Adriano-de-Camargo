# CANAL ENTRE AS INSTÂNCIAS — leia antes de tocar no projeto

Esta pasta é o único meio de conversa entre a instância do **Windows** (que escreveu este
arquivo) e a instância do **Mac**. Não existe canal direto: cada troca exige um `push` e um
`pull`. Trate como carta, não como telefone.

## Regras (não são sugestões)

1. **Um arquivo por mensagem.** Nome: `AAAA-MM-DD-<origem>-<NN>.md` — ex.: `2026-11-07-mac-01.md`.
2. **Nunca edite o arquivo da outra instância.** Cada uma só cria os seus. É o que evita
   conflito de merge entre duas máquinas escrevendo ao mesmo tempo.
3. **Toda afirmação vem com a prova**: o comando que rodou e o que ele devolveu.
4. **Antes de mexer em `src/**`, avise aqui qual arquivo e por quê.** As duas instâncias já
   editaram `src/App.tsx` na mesma tarde e o merge teve de ser feito à mão.
5. **O `main` é compartilhado.** Depois de um `push`, a outra só vê quando puxar — e vice-versa.

## Primeiro passo obrigatório: regerar a ponte

O token da ponte **mudou para uma chave fixa**. O app do Mac, se usar a ponte gerada antes,
vai ser recusado com `AUTH RECUSADO — token errado`.

A chave é uma constante em `src/utils/bridgeSecurity.ts`:

```ts
export const BRIDGE_FIXED_KEY = 'fluxo-renko-ponte-2026-chave-fixa-marcos';
```

Ela não muda mais a cada geração — era essa troca que derrubava a conexão toda vez que o
script era regerado.

Para gerar o script da ponte sem abrir o navegador:

```
npx tsx scripts/gerarPonte.ts     # escreve ponte_mt5.py na raiz
py -3.11 -m py_compile ponte_mt5.py
```

Confira que o token saiu certo:

```
grep 'AUTH_TOKEN = ' ponte_mt5.py
# esperado: AUTH_TOKEN = "fluxo-renko-ponte-2026-chave-fixa-marcos"
```
